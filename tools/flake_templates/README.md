# Шаблоны снежинок

`wedge_6.svg` — клин для 6 сгибов (30°), `wedge_4.svg` — для 4 сгибов (45°).
Нижняя точка клина — центр снежинки.

1. Откройте шаблон в Figma, Inkscape или Illustrator.
2. Нарисуйте поверх клина то, что нужно вырезать, залитыми фигурами
   (контуры, кривые, круги, прямоугольники). За края клина заходить можно.
   Обводки не считаются, только заливка.
   Можно наоборот: сложить фигуры в группу `paper` — тогда останется только
   нарисованная бумага.
3. Клин из шаблона не трогайте и не перекрашивайте: игра узнаёт его по цвету
   `#EAF4FF`, поэтому этот цвет для своих фигур не берите.
4. Экспортируйте весь холст в SVG и положите в `assets/flakes/имя.svg`.
   Снежинка станет пресетом `имя`.

Всё, что не связано с остальной бумагой, отпадёт, как при настоящем вырезании.
